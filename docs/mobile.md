# TypeWords Mobile (Tauri 2 — Android & iOS)

This fork ships the same static Nuxt UI as the [desktop app](/docs/desktop.md), wrapped with Tauri 2 for **Android** and **iOS**. Practice data still lives in **IndexedDB / localStorage** on the device; optional Supabase sync is unchanged.

| Platform | App identifier | Notes |
|----------|----------------|--------|
| Desktop | `cc.typewords.desktop` | See [desktop.md](/docs/desktop.md) |
| Android / iOS | `cc.typewords.app` | Set in `tauri.android.conf.json` / `tauri.ios.conf.json` (merged at build time) |

The Rust crate and desktop bundle id stay on `cc.typewords.desktop` in the base `tauri.conf.json` so existing desktop packaging is unchanged.

## Layout

| Path | Role |
|------|------|
| `src-tauri/gen/android/` | Android Studio / Gradle project (generated by `tauri android init`, committed) |
| `src-tauri/gen/apple/` | Xcode project (generated by `tauri ios init` on **macOS only**, then commit) |
| `src-tauri/tauri.android.conf.json` | Android-only config merge (`identifier`, `bundle.android`) |
| `src-tauri/tauri.ios.conf.json` | iOS-only config merge (`identifier`, `bundle.iOS`) |
| `.output/public/` | Frontend bundle from `pnpm run generate` (not committed) |

## Prerequisites

### All mobile targets

- Node.js (LTS) and **pnpm**
- **Rust** stable (Tauri 2.12+; use `rustup default stable` and ensure `rustc --version` ≥ 1.77)
- Run `pnpm install` at the repo root

### Android (Linux, macOS, Windows)

1. **JDK 17+** (Android Studio JBR or OpenJDK)
2. **Android SDK** with:
   - Android SDK Platform (API 35+ recommended)
   - SDK Platform-Tools
   - SDK Build-Tools
   - NDK (Side by side) — Tauri 2.12 used NDK **27.2.12479018** in CI here
   - Command-line Tools

3. Environment variables:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"   # macOS: ~/Library/Android/sdk
export NDK_HOME="$ANDROID_HOME/ndk/<ndk-version>"
export JAVA_HOME="..."                    # path to JDK
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

4. Rust Android targets:

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

Official reference: [Tauri — Android prerequisites](https://v2.tauri.app/start/prerequisites/#android).

### iOS (macOS only)

- Full **Xcode** (not Command Line Tools alone)
- Apple Silicon or Intel Mac with iOS SDK installed
- **CocoaPods**: `brew install cocoapods`
- Rust iOS targets:

```bash
rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
```

The Tauri CLI exposes `tauri ios` **only on macOS**. Linux/Windows can edit config and Android artifacts; iOS project generation and builds require a Mac.

Official reference: [Tauri — iOS prerequisites](https://v2.tauri.app/start/prerequisites/#ios).

## First-time setup

From the repository root:

```bash
pnpm install
pnpm run generate   # or let tauri mobile commands run beforeBuildCommand
```

### Android (any supported host)

If `src-tauri/gen/android/` is missing or the app id changed:

```bash
export ANDROID_HOME=... NDK_HOME=... JAVA_HOME=...
CI=true pnpm exec tauri android init
```

### iOS (Mac only)

If `src-tauri/gen/apple/` is missing (this repo may not include it until someone runs init on a Mac):

```bash
cd /path/to/TypeWords
pnpm install
CI=true pnpm exec tauri ios init
```

Commit `src-tauri/gen/apple/` after init so other Macs can open the Xcode project without re-init. Re-run init after changing `identifier` or the Rust library name (delete `gen/apple` first).

## Commands

Run from the **repository root**:

| Script | Description |
|--------|-------------|
| `pnpm run tauri:android:dev` | Dev build on emulator/device (runs Nuxt dev / generate as configured) |
| `pnpm run tauri:android:build` | Release APK (`--apk`; add `--aab` via CLI for Play-style bundles) |
| `pnpm run tauri:android:build:debug` | Debug APK (sideload / testing) |
| `pnpm run tauri:ios:dev` | iOS dev (macOS + `gen/apple`) |
| `pnpm run tauri:ios:build` | iOS release build / `.ipa` export (macOS, signing required) |

Lower-level examples:

```bash
# Debug APK, single ABI (faster CI)
pnpm exec tauri android build --debug --apk -t aarch64

# Release APK (unsigned debug keystore unless you configure signing)
pnpm exec tauri android build --apk

# iOS simulator (after init on Mac)
pnpm exec tauri ios dev --target aarch64-sim

# iOS device / App Store export (needs team + provisioning)
pnpm exec tauri ios build
```

## Android signing

Debug builds use the automatic debug keystore (not committed). For release sideloading or store upload, create your own keystore and wire Gradle signing via [Tauri’s Android signing docs](https://v2.tauri.app/distribute/sign/android/) — **do not commit** `keystore.properties`, passwords, or production keystores.

## iOS signing

- **Simulator**: no Apple Developer account required; use `tauri ios dev` / build with simulator targets.
- **Physical device or installable IPA**: requires an **Apple Developer** account, a **Development Team** in Xcode, and matching provisioning profiles / certificates. Set the team in Xcode or via `bundle > iOS > developmentTeam` in config once you have a team id.
- Environment variables `IOS_CERTIFICATE`, `IOS_CERTIFICATE_PASSWORD`, and `IOS_MOBILE_PROVISION` are read by `tauri ios build` for CI signing (keep secrets out of git).

## Build outputs

| Artifact | Typical path |
|----------|----------------|
| Android debug APK (universal) | `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk` |
| Android release APK | `src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release-unsigned.apk` (exact name may vary) |
| iOS `.app` / `.ipa` | Under `src-tauri/gen/apple/build/` after `tauri ios build` on Mac (see CLI output) |

Gradle `build/` and Xcode `DerivedData` stay gitignored; only the `gen/*/`` template tree is versioned.

## Verified on Linux (cloud agent)

Ubuntu 24.04, OpenJDK 21, Android SDK API 35 + NDK 27.2.12479018, Rust **1.99.1**:

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
pnpm install
CI=true pnpm exec tauri android init   # if not already present
CI=true pnpm exec tauri android build --debug --apk -t aarch64
```

Produced sideloadable debug APK at:

`src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`

**iOS was not built in that environment** (`tauri ios` is unavailable off macOS). On a Mac, run `CI=true pnpm exec tauri ios init` once, then `pnpm run tauri:ios:build` or `pnpm run tauri:ios:dev`.

## Troubleshooting

- **`ANDROID_HOME` / NDK errors**: install SDK components above; ensure `NDK_HOME` points at one installed NDK directory.
- **`edition2024` / old Cargo**: run `rustup default stable` and confirm `cargo --version` is recent (1.83+ may be too old for some crates).
- **Identifier / package mismatch**: after changing `identifier` in `tauri.android.conf.json` or `tauri.ios.conf.json`, delete `src-tauri/gen/android` or `src-tauri/gen/apple` and re-run the matching `tauri … init`.
- **Empty webview**: run `pnpm run generate` before mobile release builds, or use scripts that invoke `beforeBuildCommand`.

Desktop builds are documented in [desktop.md](/docs/desktop.md); `pnpm run tauri:build` remains desktop-only bundling.
